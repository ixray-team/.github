## Overview

We are a team of enthusiasts working on the development of an independent fork of the X-Ray Engine and a platform based on it, with the goal of improving all possible aspects. Our task is to provide developers with a convenient and stable platform for developing non-commercial projects

**[IX-Ray Platform](https://github.com/ixray-team/ixray-1.6-stcop)** is a series of projects aimed at forming an independent platform: for both modmakers and regular players. It provides advanced tools and support for new technologies for developing modifications based on X-Ray engine. The engine includes support for TTF fonts, NVIDIA DLSS and AMD FSR2 technologies, improved optimization and bug fixes, as well as enhanced features for creating addons using the DLTX and XMLOverride system

The platform provides a convenient and flexible environment for creating modifications through redesigned utilities and editors, as well as improving the gaming experience by increasing game performance and stability. Players can enjoy new features, improved graphics, and stable gameplay thanks to regular updates and community support
